AWX Analytics Portal

Architecture overview: A RHEL 8/9 server hosts the complete analytics stack. A Python collector syncs data from AWX (running on AWS EKS) every 5 minutes into a local PostgreSQL 15 database. A FastAPI backend serves a JSON API, proxied by Nginx to the React 18 frontend dashboard.


Components:

AWX / EKS PostgreSQL 15 Collector FastAPI Nginx
HTTPS API call (Bearer token)
DB write (INSERT/UPSERT)
DB read / HTTP proxy
Static file serving
Internal upstream proxy
